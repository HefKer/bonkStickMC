# Bonk Stick

A Minecraft mod that adds one harmless weapon for shoving mobs around. Nothing in it deals damage; it only moves things.

## Language

**Bonk Stick**:
The mod's only item: an unbreakable, unenchantable, unstackable, inedible stale baguette that Bonks instead of damaging. It can't be crafted; survival players only find it in Loot Chests.
_Avoid_: Bonk Baguette, bonk item, knockback stick

**Loot Chest**:
A structure chest that can contain a Bonk Stick. By default: dungeon (spawner-room) chests and stronghold corridor chests. Server owners can change which chests count.
_Avoid_: Dungeon (on its own, since that means only the spawner room)

**Bonk**:
A pure shove delivered by swinging the Bonk Stick at a Bonkable. It is not an attack: the target takes no damage, doesn't flash or cry out, and doesn't become hostile.
_Avoid_: Hit, attack, 0-damage hit

**Bonkable**:
Anything that can be Bonked: every living mob, every player, and armor stands (which get pushed rather than broken). By default, players can be Bonked even on servers with PvP off; server owners can make Bonks respect the PvP setting. A raised shield blocks a Bonk. Swinging it at anything else works like an ordinary empty-hand hit.
_Avoid_: Target, victim

**Bonk Strength**:
How far a Bonk pushes. At full Charge it falls between Knockback I and Knockback II, and sprinting adds more on top. Knockback resistance (iron golems, netherite) reduces it by default. Server owners can scale it and choose whether resistance counts.

**Charge**:
The attack-cooldown bar, refilling at sword speed. A Bonk's strength scales with how full the Charge is, so a spammed click is only a tap.
_Avoid_: Cooldown, wind-up

**Bonk Sound**:
The mod's own sound, played for everyone nearby on every Bonk that lands, with a slight random pitch each time. A miss is silent.
