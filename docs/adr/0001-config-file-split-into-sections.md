# Config file split into one section per feature

`config/bonkstick.json` is plain JSON with one top-level object per feature: the Bonk keys (`bonkStrength`, `respectKnockbackResistance`, `respectPvpSetting`) live under `"bonk"`, and the Loot Chest map from issue #6 goes under a sibling `"loot"` object. We chose sections over flat top-level keys because the loot map is a map of arbitrary loot-table ids, which would otherwise share one namespace with the named settings, and because a future config screen can show one category per section. The file is read once at startup and never rewritten once it exists: a value the mod can't use falls back to its own default with a logged warning, and a file that isn't valid JSON falls back to the defaults as a whole and is left for the server owner to fix.
